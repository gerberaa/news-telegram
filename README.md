# 🚀 Автономний Криптоновинний Бот

Повністю автономний бот для Telegram, який:
- 🔍 **Знаходить** криптоновини через Apify
- 🤖 **Форматує** пости через Gem## 🎯 Особливості

- **🎯 Розумна фільтрація**: AI оцінює кожну новину (публікуються тільки 8+/10)
- **📝 Повні статті**: До 4096 символів - вся інформація в пості
- **🚫 БЕЗ посилань**: Не потрібно переходити на інші сайти
- **⚡ Швидкість**: Gemini AI (2-3с на статтю)
- **🛡️ Надійність**: Автоматичне відновлення та fallback
- **🔄 Ефективність**: Адаптивні інтервали + рейтингування
- **⚙️ Гнучкість**: Легке налаштування через `.env`
- 📱 **Публікує** в Telegram канал
- 🛡️ **Запобігає** дублюванню статей

## ⚡ Швидкий старт

### 1. Встановлення залежностей
```bash
pip install -r requirements.txt
```

### 2. Налаштування змінних середовища
Скопіюйте `.env.example` в `.env` та заповніть:
```bash
cp .env.example .env
```

### 3. Запуск бота

**Windows:**
```bash
START_BOT.bat      # Повний бот з Gemini AI
FAST_BOT.bat       # Швидкий бот без AI
```

**Linux/Mac:**
```bash
python autonomous_bot.py
```

## 🔧 Налаштування

### Обов'язкові змінні в `.env`:
```ini
APIFY_TOKEN=your_apify_token
TELEGRAM_BOT_TOKEN=your_bot_token  
TELEGRAM_CHANNEL=@your_channel
```

### Опціональні налаштування:
```ini
APIFY_ACTOR=apipi~crypto-news-scraper
POLL_INTERVAL_SEC=300
MAX_ARTICLES=100
```

## 🤖 Gemini AI: Оцінювання + Форматування

Бот використовує **Gemini 2.0 Flash** для:

### 1️⃣ **Оцінювання важливості** (0-10 балів):
- 📊 Аналізує кожну новину
- 🎯 Публікує тільки найважливіші (рейтинг >= 8)
- 💎 Фільтрує малозначущі та повторювані новини

**Критерії оцінки:**
- Важливість для інвесторів/трейдерів (40%)
- Унікальність та ексклюзивність (20%)
- Актуальність та своєчасність (20%)
- Вплив на ринок/індустрію (20%)

### 2️⃣ **Повне форматування статті**:
- 🇺🇦 Українською мовою
- � Повний текст (300-800 слів) - БЕЗ посилань
- 💼 Професійний журналістський стиль
- ⚡ До 4096 символів (Telegram ліміт)
- 📄 Вся інформація В пості - не потрібно переходити

**Приклад AI статті:**
```
� Bitcoin ETF отримав схвалення SEC

Комісія з цінних паперів США (SEC) офіційно 
схвалила перший spot Bitcoin ETF від BlackRock...

[Повний детальний аналіз на 500+ слів]

� Джерело: Bloomberg
```

## 🛡️ Деуплікація

- **SQLite база** `sent_articles.db` зберігає відправлені статті
- **Хешування** за URL або title+publishedAt
- **Автоочищення** старих записів (30 днів)
- **Статистика** через `SHOW_STATS.bat`

## 🔄 Як працює бот

1. **Отримання новин** → Apify актор `dadhalfdev~cointelegraph-scraper-crypto-news`
2. **Перевірка дублів** → SQLite база `sent_articles.db`
3. **🎯 AI Оцінювання** → Gemini аналізує важливість (0-10)
4. **✂️ Фільтрація** → Публікуються тільки статті з рейтингом >= 8
5. **📝 AI Форматування** → Повна стаття українською (до 4096 символів)
6. **📤 Публікація** → Telegram Bot API (БЕЗ посилань)
7. **💾 Збереження** → Позначення як відправлено
8. **🔁 Повтор** → Кожні 3-10 хвилин
