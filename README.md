# 🚀 Автономний Криптоновинний Бот

Повністю автономний бот для Telegram, який:
- 🔍 **Знаходить** криптоновини через Apify
- 🤖 **Форматує** пости через Gemini AI
- 📱 **Публікує** в Telegram канал
- 🛡️ **Запобігає** дублюванню статей

## ⚡ Швидкий старт

### 1. Встановлення залежностей
```bash
pip install -r requirements.txt
```

### 2. Налаштування змінних середовища
Скопіюйте `.env.example` в `.env` та заповніть:
```bash
cp .env.example .env
```

### 3. Запуск бота

**Windows:**
```bash
START_BOT.bat      # Повний бот з Gemini AI
FAST_BOT.bat       # Швидкий бот без AI
```

**Linux/Mac:**
```bash
python autonomous_bot.py
```

## 🔧 Налаштування

### Обов'язкові змінні в `.env`:
```ini
APIFY_TOKEN=your_apify_token
TELEGRAM_BOT_TOKEN=your_bot_token  
TELEGRAM_CHANNEL=@your_channel
```

### Опціональні налаштування:
```ini
APIFY_ACTOR=apipi~crypto-news-scraper
POLL_INTERVAL_SEC=300
MAX_ARTICLES=100
```

## 🤖 Gemini AI Форматування

Бот використовує **Gemini 2.0 Flash** для створення привабливих постів:
- 🇺🇦 Українською мовою
- 😍 З емодзі та стилізацією
- ⚡ Швидко (1-2 секунди)
- 🎯 Адаптовано для Telegram

**Приклад AI форматування:**
```
🚀 Bitcoin знову в космосі! 💰

Сьогодні Bitcoin злетів вище $50,000! 📈 
Це сталося вперше за останні місяці...

🚀💰 Готові до зльоту? 😉
```

## 🛡️ Деуплікація

- **SQLite база** `sent_articles.db` зберігає відправлені статті
- **Хешування** за URL або title+publishedAt
- **Автоочищення** старих записів (30 днів)
- **Статистика** через `SHOW_STATS.bat`

## 🔄 Як працює бот

1. **Отримання новин** → Apify актор `apipi~crypto-news-scraper`
2. **Перевірка дублів** → SQLite база `sent_articles.db`
3. **AI форматування** → Gemini 2.0 Flash API
4. **Публікація** → Telegram Bot API
5. **Збереження** → Позначення як відправлено
6. **Повтор** → Кожні 3-10 хвилин
